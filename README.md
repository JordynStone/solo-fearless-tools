# Solo & Fearless tools

The four Solo & Fearless artifacts, served together from one place.

| Folder | What it is |
|---|---|
| `saf-diagnostic/` | The diagnostic, the entry point of the funnel |
| `sco-roadmap/` | Stop Chickening Out — the roadmap, 8 pages |
| `spis-the-bold-traveler-compass/` | Stop Playing It Small — the Bold Traveler Compass, 12 pages |
| `dream-globe/` | The community dream globe |

Each folder holds exactly what was published from its own repository, byte for
byte. Nothing here was re-styled or reworded in the move.

They were brought together so one custom domain could cover all four. A custom
domain set on a single repository affects only that repository, which keeps
every other repository on this account untouched.
